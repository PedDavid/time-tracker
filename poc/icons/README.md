# Process icons

Claude and LibreWolf SVGs are unmodified assets from [selfh.st/icons](https://github.com/selfhst/icons), revision `87a5dfd901a341e271eb453ffebce6c5a88c308e`, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). See LICENSE. Brand marks belong to their respective owners.

The report embeds these assets inline, removing XML namespace attributes for HTML and adding accessibility attributes. Terminal, code, Pi and generic process fallbacks are local artwork. No icons are fetched at runtime.
